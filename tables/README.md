
# 解釈表

原作データの解読で判明した「このゲーム固有の意味付け」を集約する領域です。
バイナリのどこに何があるか、どのコードがどの文字か、といった人間・LLM の判断はすべてここに置き、
`tools/` の変換スクリプトはこの表を読むだけで判断を持ちません。

この領域を除けば、`original/` からの復元(`recovery/`)はすべて機械的な処理になります。


## ファイル

- `message-tables.json`: メッセージ索引表・データ表の所在、ソフトウェアキーボードのかな表位置
- `data-tables.json`: 施設カタログの範囲、建設・維持費テーブルの所在と分類
- `unpack-resources.json`: UNPACK.PAK のリソース境界索引の所在
- `font-map.json`: カスタム文字コード表(16px・12px フォント)


## 値の表記

各項目は所在や範囲を表す値に加えて `status` を持ちます。

- `confirmed`: 復号結果・コード参照・字形照合などで確認済み
- `inferred`: 複数の静的な根拠が一致
- `unknown`: 未確認

`note` は判断の根拠を記します。


## 対象外

PS-X EXE や TMD、VAB など汎用フォーマットの読み方(ヘッダサイズ、マジック、レイアウト計算)は
「新テーマパーク固有の判断」ではないため、この表ではなく `tools/` 側の機械ロジックに置きます。
仮想アドレスの基準値は `tools/analysis/_psxmem.py` を参照。
