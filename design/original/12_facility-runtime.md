# 施設の配置と撤去

施設を設置すると、パーク上のタイルを占有する。施設ごとに設置費があり、
資金不足の場合は設置できない。


## 配置処理

| 項目 | 確認済みの内容 |
| --- | --- |
| 設置数上限 | 同時に設置できる施設は 64 件 |
| 資金 | 設置費を基に資金不足を確認する |
| 占有領域 | 配置予定の全タイルを確認する |
| 設置後 | 占有したタイルは施設に割り当てられる |


## 設置条件

| 対象 | 設置または変更の条件 |
| --- | --- |
| 共通 | 人または施設がある場所には設置できない |
| 一部の施設 | 高さが一定の平地にのみ設置できる |
| 歩道上の設備 | 歩道以外には設置できない |
| コース | 安全のためコースに接する場所には施設を設置できない |
| コース | 高さに上限がある |
| コース | 休止中だけ設置・変更できる |
| コース | 撤去は端からのみ行える |
| コースの乗車口 | 一周していないコースには設置できない |

設置対象ごとに、パーク内に 1 つだけ設置できるものがある。


## 撤去

施設を撤去すると、占有していたタイルが解放される。
アトラクションは運転中には撤去できない。
修理中のアトラクションも撤去できない。


## 未確認の仕様

施設ごとの幅、高さ、向き、出入口位置、初期設定値は
[施設仕様](13_facility-specifications.md) に記載する。
