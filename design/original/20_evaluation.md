# 評価

評価画面には、知名度、安全性、快適性、興奮性、ムードの 5 項目がある。
来園者が施設を利用した結果は、来園者の反応だけでなく、
評価に使う値にも反映される。

来園者の利用結果と施設の状態による評価の集計は、7 日ごとに更新される。


## 項目と要因

| 項目 | 主な増加・低下要因 |
| --- | --- |
| 知名度 | 自社広告、雑誌・テレビ紹介、来場者数達成で上がる。日付進行ごとに 10 下がる |
| 安全性 | アトラクション事故で下がる |
| 快適性 | 清掃状況と他社広告の看板に影響される |
| 興奮性 | アトラクションの興奮度と利用時のスリルに影響される |
| ムード | 設備と興奮度が低いアトラクションの設置に影響される |


## 年度末の評価

知名度は 0 から 14 枚、残り 4 項目は 0 から 15 枚のコインで表示される。
各項目が 13 枚以上になると、10,000 のボーナスを得て達成済みになる。
知名度、安全性、快適性、興奮性、ムードをすべて達成済みにすると、
スタンダードのエンディング条件を満たす。


## コイン数への変換

| 項目 | コイン数 |
| --- | --- |
| 知名度 | 内部値を 17 で割った整数値 |
| 安全性、快適性、興奮性、ムード | 内部値に 1,023 を加え、136 で割った整数値 |

安全性、快適性、興奮性、ムードの内部値は、-1,023 から 1,023 の範囲に収まる。

## 来園者区分の評価

来園者が施設を利用した結果は、来園者区分ごとの評価にも加算される。
4 区分の平均値は、企業看板の契約条件と一部のイベント条件に使われる。
