# パーク経営

パーク経営画面では、施設とスタッフを管理し、
来園者、収支、評価に関する情報を確認できる。


## 操作カテゴリ

| カテゴリ | 操作                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 建設     | 道路・モノレール、アトラクション、ショップ、設備の設置                                              |
| 人員     | スタッフの雇用と管理                                                                                |
| 経営     | 資金、価格、仕入れ、研究開発、イベント、広告                                                        |
| 情報     | パーク状況、アトラクション、ショップ、スタッフ、マーカーの表示                                      |
| システム | セーブ、ロード、アドバイス、ゲーム速度、BGM、全体マップ、視点変更、視点モード、パークへ出かける操作 |

セーブデータはメモリーカードごとに 3 件を扱う。セーブデータには日付が記録される。


## 設置と施設管理

### 道路とモノレール

| 対象       | 操作または役割                       |
| ---------- | ------------------------------------ |
| 歩道       | 来園者が歩くための道路               |
| 整列歩道   | アトラクション入口に並ぶための道路   |
| 一方通行   | 来園者の移動を制御                   |
| 案内標識   | 来園者を案内                         |
| 階段       | 来園者が段差を上り下りするための設備 |
| モノレール | 乗車口とコースを設置                 |

### アトラクション

| 操作                   | 制限または効果                     |
| ---------------------- | ---------------------------------- |
| 運転・休止             | 運転中は撤去と出入口変更ができない |
| 定員数・速度・運転時間 | 設定できる                         |
| 点検                   | 点検できるメカニックが必要。点検中は運転と出入口変更ができない |
| 乗車額・性能           | 変更または設定できる               |
| 出入口                 | 位置を変更できる                   |

アトラクション情報には、運転状態、乗車額、定員数、耐久度、興奮度、
経費、速度、利用者数、運転時間、撤去費用が表示される。

### ショップと設備

| 対象           | 操作または役割                                                               |
| -------------- | ---------------------------------------------------------------------------- |
| ショップ       | 販売価格、名称、性能を設定                                                   |
| ゲームショップ | ゲーム料金、賞品価格、勝率を設定                                             |
| 飲食ショップ   | 甘さ、肉、麺、シーフード、塩、タバスコ、辛さ、カフェイン、氷、水分の量を設定 |
| 設備           | 植物、トイレ、ゴミ箱、ベンチ、インフォメーション、イベント会場、装飾         |

ショップ情報には、販売価格、仕入価格、接客数、販売品目、在庫数、
倉庫収容量が表示される。


## 経営管理

| 機能         | 操作                                                       |
| ------------ | ---------------------------------------------------------- |
| 銀行         | 借入と返済                                                 |
| 価格         | 入場料金、アトラクションの乗車額、ショップの販売価格、ゲーム料金の設定 |
| 株式         | 売買                                                       |
| 商品         | 仕入れと倉庫への割り振り。在庫切れの商品のショップ販売は停止 |
| 研究開発     | アトラクション、ショップ、設備、バス、倉庫を対象とする項目 |
| スケジュール | イベント計画                                               |
| 宣伝広告     | パークの宣伝と広告看板                                     |

パーク状況では、資金残高、収入、支出、来園者数、入場料収入、
乗車額収入、ショップ収入、人件費、総合評価のグラフ表示を切り替えられる。
表示する年数も変更できる。

研究開発の項目ごとの解放条件と効果は未復元である。


## 来園者

### 行動と状態

| 区分       | 確認済みの内容                                           |
| ---------- | -------------------------------------------------------- |
| 移動       | 歩道を移動し、アトラクション入口では整列歩道に並ぶ       |
| 来園       | バスを利用して来園する。バスに乗れない来園希望者が発生する |
| 利用       | アトラクション、ショップ、ゲーム、ベンチ、トイレを利用   |
| 一覧       | 全員、キッズ、ヤング、カップル、ファミリーに分けて表示   |
| 個別表示   | マーカーを付けて情報を表示                               |
| 欲求・状態 | 食べ物、飲み物、所持金、利用済みの乗り物、帰宅、歩き疲れ |
| 感想       | 価格、飲食物、ゲーム賞金、乗り物への感想                 |

個別の来園者情報には、所持金、乗車数、おみやげの数、気分、滞在時間、
気持ちが含まれる。

気分と滞在時間は各 10 段階で表示される。滞在時間は入園直後から帰宅まで、
気分は「とてもつまらない」から「最高に楽しい」までの段階がある。

内部の滞在値は、入園後の毎日 5 増え、150 に達すると帰宅へ移る。
これは 30 日に相当する。

滞在値が 150 に達する前でも、来園者の内部値が -501 以下になると帰宅へ移る。

来園者の登録枠は 350 人である。

国選択に応じた補正は、来園者の初期所持金を決める処理で使われる。
経済状態ごとの基準額に 0 ～ 100 の乱数を加え、来園者種別の倍率を掛けて初期所持金を決める。
基準額は超リッチが 800、ふつうが 600、ビンボーが 400 である。

### アドバイスの対象

| 対象       | 表示される問題                                     |
| ---------- | -------------------------------------------------- |
| パーク環境 | 散らかり、雰囲気、人気低下                         |
| 移動       | 出口またはトイレを見つけられない、歩き疲れ         |
| 施設       | スリル不足、ムード不足、運転時間の短さ、乗り物不足 |
| 飲食・価格 | 飲食物の不足または不満、価格                       |
| 来園       | バスに乗れない                                     |

### 反応処理

| 項目           | 確認済みの処理                           |
| -------------- | ---------------------------------------- |
| 同時に持つ反応 | 来園者ごとに 1 つ                        |
| 更新           | 優先度を比較して反応を更新               |
| 保持期間       | 30 回の更新                              |
| 集計           | 反応の種類ごとの件数を記録               |
| 未復元         | 反応と施設設定値を結び付ける完全な計算式 |

施設の利用処理では、施設の運転状態と設定値を参照して来園者の反応を更新する。
悪い反応が発生した場合は、評価に使う値も低下する。

入場料金が来園者の価格基準を 100 より大きく上回ると、価格に関する悪い反応が発生する。
600 より大きく上回る場合は、より強い悪い反応となる。

施設を探す際、来園者は自分の候補から、所持金で利用でき、利用不可状態ではないものを絞り込む。
候補は最大 5 件であり、残った候補の中から無作為に 1 件を選ぶ。

食べ物または飲み物を求める内部値が 150 以上になると、対応する飲食施設を探す。

食べ物と飲み物を求める内部値は、満たされるまで更新ごとに 1 増える。
250 に達した後も満たされない場合、来園者の内部値が更新ごとに 1 下がる。

整列歩道で待機中、来園者の待機値は更新ごとに 1 増える。待機値が 250 に達しても
利用できない場合、目的地を正面ゲートへ切り替える。

来園者の到着条件と、待ち行列を離れる詳細な条件は未復元である。

| 設備               | 来園者への効果                   |
| ------------------ | -------------------------------- |
| ゴミ箱             | 来園者が歩道にゴミを捨てなくなる |
| インフォメーション | 迷子を預かる                     |
| イベント会場       | 来園者区分ごとに人気の対象を持つ |

案内標識は正面ゲートまたはトイレを探す来園者への案内に使う。
ベンチは歩き疲れた来園者への対策に使う。
食べ物・飲み物ショップを利用した来園者はゴミを出し、近くにゴミバコがなければ歩道に捨てる。


## スタッフ

| 種類               | 役割                               |
| ------------------ | ---------------------------------- |
| メカニック         | アトラクションの修理と点検         |
| スイーパー         | パークの清掃                       |
| ガードマン         | マナーの悪い来園者からパークを守る |
| ウサギのぬいぐるみ | 来園者を楽しませる                 |
| グーチョくん       | 来園者を楽しませる                 |
| ミュージシャン     | 来園者を楽しませる                 |

| 管理項目             | 内容                                           |
| -------------------- | ---------------------------------------------- |
| 全スタッフ           | 月給、位置、能力、解雇                         |
| スイーパー           | 清掃ルート                                     |
| 清掃ルートの制限     | 同じ高さの場所だけに設定できる                 |
| 清掃ルートの操作制限 | 仕事中またはストライキ中は変更できない         |
| ストライキ           | 位置変更、解雇、清掃ルートの操作に制限がかかる |

スタッフは最大 64 人まで雇用できる。スタッフ種類ごとに別の更新処理が呼び出される。

月給が低いと、スタッフが怒ることがある。
スタッフ情報には、月給、雇用年数、能率、職種、ウケた数が表示される。

| 種類 | 月給・雇用費 | 詳細 |
| --- | ---: | --- |
| メカニック | 2,000 | 耐久度が低いアトラクションへ向かい、修理後に耐久度を全快する |
| スイーパー | 2,000 | 歩道のゴミ、トイレ、ゴミバコを清掃する。清掃ルートは最大 72 マス |
| ガードマン | 5,000 | 迷子を保護し、アウトローを退治する。最大 5 人 |
| ウサギのぬいぐるみ | 2,000 | 近くの来園者を楽しませる。最大 5 人 |
| グーチョくん | 4,000 | 近くの来園者を楽しませる。最大 5 人 |
| ミュージシャン | 6,000 | 近くの来園者を楽しませる。最大 5 人 |

スタッフの初期能率は 100 である。能率は月をまたぐと下がることがあり、
4 月 10 日の労使交渉が成立すると回復する。スタッフの半数以上の能率が 0 になると、
全員が仕事を放棄するストライキが発生する。30 年勤務したスタッフは定年退職する。


## 進行と結果

| 項目         | 確認済みの内容                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| 時間         | 進行速度を設定できる                                                                                                 |
| シナリオ     | 達成条件を満たすか、期限が過ぎると結果画面が表示される                                                                 |
| 通常イベント | 事故、乱闘、人気タレントの訪問、消費者団体の視察、雑誌での紹介、スタッフのストライキ、広告契約の終了、研究開発の終了 |
| イベント会場 | 客層、季節、時間帯による利用可能範囲がある                                                                           |
| 天候         | 悪天候時はイベントを中止する                                                                                         |
| ランダムイベント | 発生条件と結果は [イベント](22_events.md) に記載する                                                               |

イベント計画は、パークの面白さが足りず人気が落ちている場合の対策として案内される。
宣伝広告は、パークを知る来園希望者が少ない場合の対策として案内される。
