# 確認範囲

この文書は、原作再現に使える確認済みの内容と、抽出済みだが意味を特定していないデータを区別する。


## 確認済み

- 国名は 10 種類であり、名称は [ゲーム概要](00_game-overview.md) に記載する
- 施設名は 76 種類であり、名称と ID は [施設](10_facilities.md) に記載する
- 全施設の設置費、維持費、コース型施設のコース単位設置費は [経済](11_economy.md) に記載する
- 施設の配置と撤去は [施設の配置と撤去](12_facility-runtime.md) に記載する
- 入場料金と施設料金の初期値は [経済](11_economy.md) に記載する
- 評価は知名度、安全性、快適性、興奮性、ムードの 5 項目であり、詳細は [評価](20_evaluation.md) に記載する
- 研究開発の対象、難易度による操作差、アトラクション分岐は [研究](21_research.md) に記載する
- 画面文言の正本は `recovery/manifests/messages-decoded.json` とする
- パーク経営中の操作、来園者、スタッフ、進行は [パーク経営](01_park-management.md) に記載する
- パークのタイル領域、正面ゲート、道路接続は [パークマップ](02_park-map.md) に記載する
- モード選択と時間進行は [モードと時間](03_game-modes-and-time.md) に記載する
- 国別シナリオの初期状態と達成条件は [シナリオ](04_scenarios.md) に記載する
- 施設の面積、能力、定員、開発費は [施設仕様](13_facility-specifications.md) に記載する
- バスと倉庫の段階別性能は [バスと倉庫](14_bus-and-warehouse.md) に記載する
- パークへ出かける操作で遊ぶミニゲームは [ミニゲーム](15_minigames.md) に記載する
- 計画イベントとランダムイベントは [イベント](22_events.md) に記載する
- 媒体広告と企業看板の契約は [宣伝広告](23_advertising.md) に記載する
- パークの地形と施設は 2D 表現であり、来園者は方向別の 2D 画像で表現される
- 地面・道路・来園者の画像データは抽出済みである
- 来園者の施設利用は、施設の状態と設定値に応じて反応と評価に使う値を更新する
- スタッフは最大 64 人まで雇用でき、種類ごとに別の行動処理を持つ
- 来園希望者の一部はバスの定員不足によりパークへ来られない
- ショップは商品の在庫切れで販売を停止する


## 復元コードの範囲

メイン実行部と `PRO/` の各プログラムは、復元コードから関数単位で参照できる。
ただし、プログラム末尾などの非実行領域を解析器が関数として扱う場合があるため、
仕様の根拠には実行経路またはデータ参照で裏付けられる処理だけを使用する。


## 重要な未確認事項

以下は、原作に近いゲームを実装するために仕様の復元が必要な項目である。

| 分類 | 未確認の内容 | 静的解析で確認できる資料 |
| --- | --- | --- |
| 時間 | 停止時を含むゲーム速度ごとの日付進行の現実時間 | 日付進行の内部間隔は確認済み。実時間への換算は実機またはエミュレータでの計測が必要 |
| 施設 | 出入口位置、運転時間と速度の初期値 | 設置と設定の処理、施設データがある。設定値と施設ごとの対応付けが未完了 |
| 来園者 | 施設の選択計算、待ち行列を離れる詳細な条件 | 来園者と施設の状態遷移処理がある。状態値の意味と条件の対応付けが未完了 |
| 評価 | 各評価値の完全な増減式 | 評価値の更新処理がある。すべての要因と増減量の対応付けが未完了 |
| スタッフ | 距離や能率を使う作業対象の選択式 | 職種ごとの更新処理がある。内部状態と対象選択の対応付けが未完了 |


## 抽出済みだが用途未解釈のデータ

- `PRO/MAPVIEW.BIN`: パーク内マップに関するプログラムとデータ
- `3D/D00/GND000.BIN`、`GND001.BIN`、`GND002.BIN`: 地面・道路の画像データ
- `TEX/PEOPLEA.BIN` から `PEOPLEI.BIN`: 来園者の方向別画像データ
- 画像、音声、動画と、施設または画面の対応関係


## 記載方針

存在を確認していない機能やデータは、この仕様書に記載しない。抽出済みでも意味を特定できていない内容は、原作仕様として実装しない。
