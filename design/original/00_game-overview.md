# ゲーム概要

本作はテーマパークを運営するゲームである。国は日本、アメリカ、ブラジル、イギリス、フランス、エジプト、ロシア、インド、中国、オーストラリアの 10 種類である。


## パーク画面

パークの地形と施設は、2D の画像で高低差を表現する。来園者は方向別の 2D 画像で表現される。


## 実装するゲームの流れ

プレイヤーは国とモードを選び、初期化されたパークを経営する。
パーク内に道路と施設を設置し、スタッフ、価格、研究開発、広告などを管理する。

来園者は道路を移動して施設を利用し、価格や施設、パーク環境に反応する。
時間の進行に合わせて収支と評価が更新され、イベントやモード固有の処理が行われる。
