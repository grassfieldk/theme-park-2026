月替わりの処理で支出として計上される。

## 料金

料金設定では、パーク全体の入場料金、アトラクションの乗車額、ショップの販売価格、
ゲーム料金を変更できる。これらは設置費・維持費とは別の値である。

| 料金                   | 初期値 |
| ---------------------- | -----: |
| パーク全体の入場料金   |    100 |
| アトラクションの乗車額 |    100 |
| ショップの販売価格     |    100 |
| ゲーム料金             |    100 |

施設を設置すると、料金設定値は施設種別にかかわらず 100 で初期化される。
この値は来園者が施設を利用するときの支払い計算に使われる。
国の選択値が初期料金の計算へ渡ることは確認できていない。

料金は 0 から 9,999 の範囲で設定できる。

入場料金は、来園者が正面ゲートで入園するときに所持金から差し引かれ、入場料収入として記録される。
所持金が入場料金に足りない来園者は入園しない。

来園者が施設を利用すると、料金が所持金から差し引かれ、施設利用による収入として記録される。

施設利用時の支払額は、設定料金に来園者区分ごとの人数倍率を掛けた額である。

| 来園者区分 | 人数倍率 |
| ---------- | -------: |
| キッズ     |        1 |
| ヤング     |        1 |
| カップル   |        2 |
| ファミリー |        3 |


## 資金不足

総資金が負になると、資金がマイナスになったことを知らせる警告が表示される。
総資金が正へ戻ると警告状態は解除され、再び負になったときは再度警告される。


## 銀行

借入額と返済額は 1,000 単位で設定する。借入額は借入限度額を超えられず、
返済額は借入残高と所持金を超えられない。

借入には月ごとの利息がある。借入残高は、借入日から 2 年後の同じ日付に一括返済される。

借入画面に表示される利率は国ごとに固定されている。

## 商品在庫

ショップで販売する商品は、在庫がなくなると販売できない。
商品は仕入れ画面から仕入れる。仕入れ量を確定した時点で、単価と仕入れ量に応じた費用を支払う。
資金が足りない場合、仕入れ量は支払える範囲に制限される。

上級では、発注からゲーム内で 7 日後に、発注量が在庫へ加算される。
在庫は倉庫の収容上限を超えて加算されない。

仕入れ画面には、アイスクリーム、ハンバーガー、ポップコーン、ステーキ、ピザ、
コーラ、コーヒー、ビール、うどん・そば、カレー、アメリカンドック、ラーメン、
クレープ、シーフードの 14 商品の情報項目がある。

上級では、飲食ショップで商品が売れるたびに在庫が減る。

内部の在庫枠は 9 種類である。仕入れ画面の 14 商品の情報項目とは一致しない。

| 在庫枠 | 対応するショップの商品                                                 |
| -----: | ---------------------------------------------------------------------- |
|      1 | アイスクリーム                                                         |
|      2 | ハンバーガー                                                           |
|      3 | ポップコーン                                                           |
|      4 | ステーキ                                                               |
|      5 | ピザ                                                                   |
|      6 | コーラ                                                                 |
|      7 | コーヒー                                                               |
|      8 | ビール                                                                 |
|      9 | シーフード、ラーメン、クレープ、カレー、うどん・そば、アメリカンドック |

飲食ショップでの販売ごとに、在庫枠の減少量の基準は次のとおりである。

| 来園者区分 | 減少量 |
| ---------- | -----: |
| キッズ     |      1 |
| ヤング     |      1 |
| カップル   |      2 |
| ファミリー |      3 |

実際の減少量は、基準量に販売設定の段階に応じた倍率を掛ける。

| 対象                             | 設定段階 0・1 |    設定段階 2 | 設定段階 3・4 |
| -------------------------------- | ------------: | ------------: | ------------: |
| コーラ・ビール以外の飲食ショップ | 基準量の 1 倍 | 基準量の 2 倍 | 基準量の 3 倍 |
| ドンキーコーラ・ビアホール       | 基準量の 3 倍 | 基準量の 2 倍 | 基準量の 1 倍 |

飲食ショップを設置した直後の販売設定は段階 0 である。


## 設備

設備には維持費がない。設置費は 1 回の設置ごとにかかり、つなげて置く設備は 1 マスごとにかかる。

機嫌が変わる範囲は設備の大きさに応じて広がる。トイレ、スーパートイレ、ゴミバコは
設置した瞬間だけ周囲の来園者の機嫌を下げるが、パーク評価は大きく上げる。

## 株式

株式は 10 銘柄を売買できる。購入額と売却額は、株価の 10 倍に取引株数を掛けた額である。

保有数は銘柄ごとに最大 9,999 株である。購入できる株数は、所持金と保有上限によって制限される。
売却できる株数は、保有数を超えない。

株価は 7 日ごとに更新される。初期株価と更新値には乱数が使われる。
