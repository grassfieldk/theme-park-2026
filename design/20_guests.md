# 来園者

来園者はバスで来園し、歩道を移動して施設を利用し、時間の経過とともに帰宅する。
来園者の登録枠は 350 人である。


## 来園者区分

来園者はキッズ、ヤング、カップル、ファミリーの 4 区分である。
一覧表示では全員と区分別を切り替えられる。

| 来園者区分 | 人数倍率 |
| ---------- | -------: |
| キッズ     |        1 |
| ヤング     |        1 |
| カップル   |        2 |
| ファミリー |        3 |

人数倍率は施設利用時の支払額と、飲食ショップの在庫消費量に掛かる。
ファミリーは 3 人で行動するため、接客数や定員が少ない施設では
先客がいる間は利用できない。

キッズは来園時に一定の確率で迷子になる。
キッズはビアホールを利用できない。


## 所持金

国選択に応じた補正は、来園者の初期所持金を決める処理で使われる。
経済状態ごとの基準額に 0 ～ 100 の乱数を加え、来園者種別の倍率を掛けて初期所持金を決める。

| 経済状態 | 基準額 |
| -------- | -----: |
| 超リッチ |    800 |
| ふつう   |    600 |
| ビンボー |    400 |

所持金が入場料金に足りない来園者は入園しない。
所持金がなくなった来園者は帰宅する。

入場料金は、敷地の中の歩道に足を踏み入れたときに 1 回だけ差し引かれる。
入園していない来園者はゲート下の固定歩道を歩けるので、園外に出てもゲートへ戻れる。
ショップ・アトラクション・設備の利用に入園の有無は関わらないため、
園外に置いたものは入園前の来園者も使い、代金も支払う。

一方で入園済みの来園者は固定歩道を歩けないので、園外へ出ることがない。
つまり園外の施設は、入園前の来園者と帰宅する来園者だけが使う。
これは意図した仕様で、入園させずに園外のアトラクションだけで稼ぐ遊び方を
成り立たせるためのもの。快適性の判定は入園するときに行うため、入園しなければ
[企業看板](25_advertising.md#企業看板)の不利を受けずに済む。


## 行動と状態

| 区分       | 内容                                                       |
| ---------- | ---------------------------------------------------------- |
| 移動       | 歩道を移動し、アトラクション入口では整列歩道に並ぶ         |
| 来園       | バスを利用して来園する。バスに乗れない来園希望者が発生する |
| 利用       | アトラクション、ショップ、ゲーム、ベンチ、トイレを利用     |
| 個別表示   | マーカーを付けて情報を表示                                 |
| 欲求・状態 | 食べ物、飲み物、所持金、利用済みの乗り物、帰宅、歩き疲れ   |
| 感想       | 価格、飲食物、ゲーム賞金、乗り物への感想                   |


## 滞在と気分

気分の内部値は -512 から 511 の範囲に収まる。来園時は 0 で、施設を利用したときの
評価点の 1/10 が加算される。ほかに次の場合に下がる。

| 場面                                     | 気分の変化 |
| ---------------------------------------- | ---------: |
| 満腹度・水分が尽きた/疲労が限界のまま更新される |     -1 |
| トイレ欲求が限界に達して我慢できなくなる |       -100 |
| 散らかった歩道の許容量を使い切る         |       -500 |
| アトラクションが故障した状態で乗る       |       -500 |
| 整列歩道で待ちくたびれて列を離れる       |        -50 |

気分と滞在時間は各 10 段階で表示される。

| 段階 | 滞在時間       | 気分             |
| ---: | -------------- | ---------------- |
|    1 | 今来たところ   | とてもつまらん   |
|    2 | 着いたばかり   | つまらない       |
|    3 | ほんのちょっと | わりと退屈       |
|    4 | ちょっとたった | ちょっと退屈     |
|    5 | すこしたった   | まあまあ         |
|    6 | しばらくたった | ちょっと楽しい   |
|    7 | だいぶたった   | 楽しい           |
|    8 | だいぶいる     | かなり楽しい     |
|    9 | 長いこといる   | とても楽しい     |
|   10 | もう帰る       | 最高に楽しい     |

内部の滞在値は、入園後の毎日 5 増え、150 に達すると帰宅へ移る。これは 30 日に相当する。

滞在値が 150 に達する前でも、来園者の内部値が -501 以下になると帰宅へ移る。


## 施設の選択

施設を探す際、来園者は自分の候補から、所持金で利用でき、利用不可状態ではないものを絞り込む。
候補は最大 5 件であり、残った候補の中から無作為に 1 件を選ぶ。

満腹度または水分が 100 を下回ると、対応する飲食施設を探す。

満腹度と水分は 0 〜 250 の内部値で、来園時は 250 である。更新ごとに 1 減り、
0 になった後も満たされない場合、来園者の気分が更新ごとに 1 下がる。

来園者の内部値の更新は、ゲーム速度に依らず 1 日あたり 15 回である
(更新間隔は高速 5・標準 10・低速 20 フレームで、1 日は高速 75・標準 150・低速 300 フレーム)。

疲労は歩いている間、更新ごとに 3 増える(上限 250)。
250 のまま歩き続けると、来園者の内部値が更新ごとに 1 下がる。
疲労はベンチとトイレの利用で回復する([設備](16_amenities.md) に記載)。

飲食ショップを利用すると、満たす側の内部値をいったん 100(探し始めるしきい値)まで
戻してから、商品ごとの値を足す。こうすると、我慢して 0 まで落ちていた来園者でも
必ずしきい値より上まで戻るので、食べた直後にまた食べたくなることがない。
我慢したぶんは 0 に張り付いていた間の気分の減点として残っている。

原作は逆向きの「空腹値」「渇き値」を持ち、更新ごとに増えて 150 以上で店を探し、
250 で頭打ちになる作りだった。さらに別の内部値として満腹値を持ち、食べると 250 になって
更新ごとに 10 減り、その間だけ対応する内部値が増えなかった。
本作は満腹度・水分が減っていく向きに変え、満腹値は持たない。
原作は満腹値が食べ物と飲み物で共用だったため、飲むと食べ物の腹持ちまで伸びる
という不自然さもあった。

持っていたゴミは、満腹度・水分が 150 を下回っている間に一定数たまると歩道へ落とす。
判定のしかたは [ポイ捨ての判定](#ポイ捨ての判定) に記載する。
本作のゴミの扱いは原作と異なる独自仕様で、[設備](16_amenities.md) に記載する。

整列歩道で待機中、来園者の待機値は更新ごとに 1 増える。待機値が 250 に達しても
利用できない場合、目的地を正面ゲートへ切り替える。


## 反応処理

来園者は反応を 1 つだけ持ち、頭の上にアイコンで表示する。

- 反応には強さの順位があり、今の反応と同じか強い反応は即座に置き換わる。
  弱い反応は、今の反応を出しきったあとでなければ出ない
- 出た反応は一定フレーム保たれ、残りが規定を切るとアイコンだけ消える。
  出しきると、そのときの状態から反応を選び直す
- 反応の種類ごとに、発生した件数をパーク全体で記録する(上限 250)

保つ長さは 30 フレーム、アイコンを消すのは残り 15 を切ったときである。
内部フレームは 30 fps なので、保つ長さは 1 秒、アイコンが出ているのは 0.5 秒になる。
1 日あたりのフレーム数は速度によって変わるがフレームの刻み自体は変わらないので、
表示の長さはゲーム速度に依らない。

当てはまる条件が複数あるときは、選び直すたびに順位の近い反応どうしが入れ替わるため、
その間はアイコンが出続ける。

反応を選び直すときは、次の条件を上から順に調べる。
強さの順位があるので、当てはまるもののうち最も強い反応が残る。

| 条件                                       | 反応                           |
| ------------------------------------------ | ------------------------------ |
| 満腹度と水分の両方がしきい値未満           | 何か口にしたい                 |
| 満腹度がしきい値未満                       | 何か食べたい                   |
| 水分がしきい値未満                         | 何か飲みたい                   |
| 気分が -500 以下                           | そろそろ家に帰ろう             |
| 乗った種類が園内の全種類と同じ             | ここにある乗り物には全部乗った |
| 乗った種類が園内の 7 割以上                | ほとんどの乗り物に乗った       |
| 滞在値が 150 以上                          | もう帰る                       |
| 滞在値が 150 以上で、疲労が限界            | 出口はどこだろう？             |
| トイレ欲求が 200 超で、疲労が 50 以上      | トイレはどこだろう？           |
| 散らかりの許容量が 100 未満                | ずいぶん散らかっているな       |
| 疲労が限界                                 | もう歩きたくない               |
| 気分が 400 以上                            | おもしろい！                   |
| 気分が -400 未満                           | つまらない                     |

どれにも当てはまらない場合はアイコンを出さない。

このほか、施設を利用しようとしたとき・利用したときにも反応が発生する。
悪い反応が発生した場合は、施設の評価に使う値も低下する。

入場料金が来園者の価格基準を 100 より大きく上回ると、価格に関する悪い反応が発生する。
600 より大きく上回る場合は、より強い悪い反応となる。

## アウトロー

アウトローはパークへ侵入する来園者である。名前はさめちゃん、ジャイアントレイ、
ハッスルほんだ、モッチーの 4 種類だが、**見た目は 4 人とも同じ**で、
出現のたびに名前だけが選ばれる。

パークの知名度が高いほど出現しやすい。

### 登場と退場

アウトローはバスに乗らず、二人乗りのバイクで単身乗り付ける。

- バイクはバスと同じゲート下の道を右から左へ走る
- ゲート下の中央でいったん停まり、アウトローだけを降ろして走り去る。
  降りた瞬間にバイクの絵が「運転手とアウトローの 2 人乗り」から「運転手だけ」に替わる
- バスとバイクは同じ道を走るので、相手が走っている間は入ってこない。
  バスの発車が重なったときは、バイクが走り抜けてから出る
- アウトローは入場料を払わず、ゲートをいつでも通り抜ける
- 買い物も乗車も設備の利用もせず、道路をただ歩き回る
- 決まった日数が過ぎるとゲート下へ戻って立ち止まり、迎えのバイクを待つ。
  迎えは運転手だけで来て、いったん停まってアウトローを乗せ、2 人乗りの絵に替わって走り去る。
  バスが走っている間は迎えを呼べないので、道が空くまでその場で待つ

出現の判定は 7 日ごとに行い、園内に居る間とバイクが走っている間は判定しない。
原作は知名度から出現率を出すが、本作は知名度が未実装なので一律の確率にしている。
確率は、滞在の 20 日と当たるまでの平均を足しておよそ 3 か月に 1 回になるよう決めた。

### 影響

アウトローがキッズと同じマスに来ると、そのキッズの気分が大きく下がる。
続けて何度も下がらないよう、同じキッズには少し間を空ける。

原作ではさらにそのキッズのパーク評価と、パークの安全性が下がり、
後に乱闘事件として報道されるが、パーク評価・安全性・報道はまだ扱っていない。
キッズが泣く絵も、反応アイコン 32 種の中にないため出していない。

アウトローとガードマンが接触すると戦闘になる。
ガードマンが勝てばアウトローを退治し、負ければガードマンがしばらく動けなくなる。
勝率はガードマンのバージョンが高いほど上がる。
原作は負けるとアウトローがパークの奥へ侵入するとされるが、
アウトローはもともと自由に歩き回るため、本作では区別していない。
詳細は [スタッフ](21_staff.md#ガードマンの動き) に記載する。


## 迷子

原作は種別 7・8(ファミリー)の来園者が迷子になる(D2MAIN `FUN_801efb78`、
`*(ushort *)(param_1 + 2) - 7 < 2` で種別を判定)。判定条件は原作コードで確認できた。

- 疲労(+0xd0)が 100 以下であること
- 徘徊中の状態(状態番号 +0xc8 が 0)であること
- パーク全体で迷子は同時に 1 件まで(`_DAT_8014f560` の 0x40/0x20 ビットで管理)
- 上記を満たす間、毎更新 20 %(乱数 `func_0x800b0b70`、0〜99 のうち 80 以上)で発生

「迷子を出してよい」状態(0x40)は、迷子が出た時点で下りる。立て直しているのは
`FUN_801f1894` で、日ごとの処理から呼ばれ、次の判定で立て直す。

```
乱数(0〜99) + 1 < パークの資産価値 ÷ 年間来場者数 ÷ 100
```

- **パークの資産価値** = `0x8016bdc8`。初期資金から始まり、設置費(会計の項目 5)を
  積み上げる。`0x8016bdc4`(= その 1/2000 × 1000)の元にもなっている
- **年間来場者数** = `0x8016bd02`。13 年ぶんの履歴配列の先頭で、年が替わると
  `FUN_800b4004` が 1 つずらして 0 に戻す。日本とイギリスのシナリオ達成条件
  「年間来場者数 2,000 超」が見ているのもこの値

つまり**資産の割に来場者が少ないパークほど迷子が起きやすい**。本作も同じ式にしてある。

本作もファミリー区分の来園者が対象で、疲労 100 以下・パーク全体で同時に 1 件までは
原作どおりに合わせた。発生確率は原作の毎フレーム判定をそのまま持ち込むと動作間隔の
基準が異なり体感が変わるため、内部値の更新ごとの確率に独自の値を当てている
(1 件までの制約があるため、体感の頻度自体は大きく変わらない想定)。

迷子になると、はぐれた**子**が親と同じ姿でその場に現れる
(原作は `FUN_801e48bc(0x18 - 種別, x, y)` で種別 16 / 17 の実体を作り、
バンクは親と同じファミリーのものを使う)。子は買い物も乗車もしない。

そのあとの動きは次のとおり。

- **インフォメーションがあると**、親も子もそこを目指して歩く。原作は設置したときに
  その位置を 1 つだけ覚えており、迷子が出ると親の目的地をそこにし、
  子も手が空くたびにそこを目指す
- **無ければ**どちらも普段どおり歩き回り、たまたま同じマスで出会えば再会する
- 再会すると、親の疲労・満腹度・水分・気分を子と平均する
- 親が帰るときは子も一緒にゲートへ向かう

迷子はパーク全体で同時に 1 件までなので、解決するまで次の迷子は出ない。
解決したあとも、日ごとの抽選に当たるまでは次の迷子が出ない。

ガードマンは子を抱えて親のところまで運ぶ。親が帰ってしまっていれば
インフォメーション、それも無ければガードマンの持ち場へ運んで解放する。

ガードマンの保護の動きは [スタッフ](21_staff.md#ガードマンの動き) に記載する。


## 歩道の汚れ

歩道のマスは飲み物のゴミ・食べ物のゴミ・ゲロの 3 つを別々に持ち、
1 つのマスに 3 種類とも重なりうる。絵は道路の上に重ねて描く。

| 種類         | 出るとき                                       |
| ------------ | ---------------------------------------------- |
| 飲み物のゴミ | 我慢できる数を超えて捨てるとき、飲み物のゴミを持っていれば |
| 食べ物のゴミ | 我慢できる数を超えて捨てるとき、食べ物のゴミを持っていれば |
| ゲロ         | 酔いが限界に達したとき                         |

歩道を撤去すると、その上の汚れも一緒に消える。

### ポイ捨ての判定

来園者は屋台型の飲食ショップを利用するたびにゴミを 1 個持つ(独自仕様)。
満腹度か水分が 150 を下回っている間、持っているゴミの合計が
我慢できる数に達していれば、内部値の更新のときに足元へすべて捨てる。
それまでにゴミバコやトイレへ寄って手ぶらになっていれば落とさない。

歩道は種類の有無しか持たないので、同じ種類を何個捨てても絵は 1 つである。
個数を持たないぶん、歩道には実質いくらでも捨てられる。

我慢できる数は国ごとに違う。

| 我慢できる数 | 国                             |
| -----------: | ------------------------------ |
|            5 | 日本、イギリス、フランス       |
|            3 | アメリカ、ロシア、オーストラリア |
|            1 | ブラジル、エジプト、インド、中国 |

ゴミバコとトイレへ捨てるほうは国によらず、1 個でも持っていれば捨てる。
捨て先の扱いは [設備](16_amenities.md#ゴミの独自仕様) に記載する。

### 酔い

来園者は乗り物に乗るたびに酔いがたまる。201 を超えると乗らなくても
内部値の更新ごとに 2 ずつ増え続け、249 に達すると足元に吐いて 0 に戻る。

原作は「アトラクションごとの酔いやすさ × 速度設定」で増やすが、
酔いやすさの表がまだ取れていないので、本作は速度設定だけで増やしている。

### 汚れの影響

汚れたマスを踏むたびに、その来園者の我慢(初期値 250)が 2 減る。
100 を下回ると「ずいぶん散らかっているな」の反応が出る。
使い切ると気分が 500 下がり、以後その来園者はもう下がらない。

スイーパーによる清掃はスタッフが未実装なので、汚れは撤去以外では消えない。
