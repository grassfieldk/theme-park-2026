# 宣伝広告

宣伝広告には、費用を払って出す媒体広告と、企業看板の契約がある。


## 媒体広告

媒体広告では、次の 4 種類から 1 つを選ぶ。広告を出す時点で費用を支払う。

| 媒体   |    費用 | 知名度の加算値 | 評価用の 4 内部値への加算値 |
| ------ | ------: | -------------- | --------------------------- |
| 新聞   | 100,000 | +70            | +100, +100, +100, +100      |
| 雑誌   | 100,000 | +70            | +200, +200, +0, +200        |
| ラジオ |  50,000 | +30            | +0, +0, +100, +100          |
| テレビ | 200,000 | +150           | +200, +200, +200, +200      |

広告を確定すると、上表の固定効果をただちに加算する。続いて広告結果を処理し、
好評なら知名度を 10 上げ、不評なら 10 下げる。好評・不評は乱数によって
選ばれ、乱数値が 50 未満なら不評となる。

媒体広告を出すと、パークの知名度が上がり来園希望者が増える。


## 企業看板

企業看板は企業と契約してパーク内に出す。契約すると広告料を受け取る。

同じ企業とは同時に契約できない。契約は最大 3 件までである。
契約の終了日は、契約日から 2 か月後の同じ日付である。同じ日付がない月では月末になる。

企業ごとに、契約に必要なパークの人気の条件がある。

| 企業名           | 企業種別   | 契約時の広告料 | 必要な人気の内部値 |
| ---------------- | ---------- | -------------: | -----------------: |
| マーメイド化粧品 | 化粧品     |         50,000 |                  0 |
| ドンキーコーラ   | 清涼飲料水 |         10,000 |                  0 |
| パンサー自動車   | 自動車     |        100,000 |              1,000 |
| コング玩具       | おもちゃ   |         30,000 |                500 |
| コンドル製菓     | お菓子     |         20,000 |                200 |
| カンガルータバコ | タバコ     |         80,000 |               -500 |
| ライオン電機     | 電化製品   |         40,000 |                500 |
| ペンギンフィルム | フィルム   |         60,000 |                  0 |
| スネーク薬品     | 薬         |         80,000 |                200 |
| バットビール     | ビール     |         70,000 |               -500 |

必要な人気の内部値は、[評価](22_evaluation.md) の来園者 4 区分の評価平均である。

パーク内に設置された企業看板は、快適性の評価を下げる。

快適性の判定は、来園者が入園するときに行う。タバコやビールの看板を出していると
このとき快適性が大きく下がる。逆に言えば、入園しない来園者には判定が働かない。
園外にアトラクションを置いて入園させずに遊ばせると、看板の不利を受けずに
広告料と乗車額だけを得られる([来園者](20_guests.md#所持金))。
