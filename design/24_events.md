# イベント

イベントには、予定して開催する屋外・屋内イベントと、条件により発生する
ランダムイベントがある。イベントはスケジュール画面で計画する。


## 屋外イベント

屋外イベントは全客層の疲労とストレスを下げ、パークの活性度を上げる。
雪または雨の日は中止になる。

| ------------------------ | ----: | -------- | -----: | -------------- |
| カーニバルパレード       | 6,200 | 全客層   |   6/10 | 朝・昼         |
| ファンタジックパレード   | 8,000 | 全客層   |   8/10 | 朝・昼         |
| 花火大会                 | 7,000 | 全客層   |   7/10 | 夕方・夜       |
| 大花火祭り               | 9,900 | 全客層   |  10/10 | 夕方・夜       |
| ナイトパレード           | 7,500 | 全客層   |   7/10 | 夜             |
| ドリームパレード         | 9,200 | 全客層   |   9/10 | 夜             |
| クリスマスフェスティバル | 9,000 | 全客層   |   9/10 | 12 月の夜      |
| ニューイヤーパーティー   | 8,500 | 全客層   |   9/10 | 1 月の朝       |

## ランダムイベント

| イベント         | 発生条件                           | 主な結果                                                                               |
| ---------------- | ---------------------------------- | -------------------------------------------------------------------------------------- |
| 乱闘事件報道     | アウトローがパークへ侵入           | 報道自体の評価低下はない                                                               |
| 事故報道         | アトラクションが爆発               | 安全性、パーク評価、客層別評価が下がる                                                 |
| 雑誌・テレビ紹介 | 知名度または話題性                 | 知名度、アトラクション評価、客層別評価が変わる                                         |
| 消費者団体来訪   | ランダム                           | 価格が高い場合は評価が下がる                                                           |
| 人気タレント来訪 | 知名度                             | 満足した場合は安全性、快適性、興奮性、ムードが各 200 上がり、不満の場合は各 200 下がる |
| 映画撮影         | 知名度、快適性、ムード             | 知名度とムードが上がる                                                                 |
| ストライキ       | スタッフの半数の能率が 0           | 全スタッフが仕事を放棄する                                                             |
| 来場者数達成     | 累計来場者数が 1 万、10 万、100 万 | 知名度が上がる                                                                         |
| 創立記念         | 10 年ごとの 4 月 1 日              | 知名度が上がる                                                                         |
| 財宝発見         | 施設設置時のランダム判定           | 資金が 100,000 増える                                                                  |
| 定年退職         | 同じスタッフが 30 年勤務           | スタッフが退職する                                                                     |
| 広告契約の終了   | 企業看板の契約期間の満了           | 契約が終了する                                                                         |
| 研究開発の終了   | 累計投資額が開発費に到達           | 施設が開発される                                                                       |

来訪する人気タレントの名前は、サンロー、シュワチャン、マイコーチャクソン、
エルビスグリズリ、セイコチャン、ジュエリーロバーツ、ハリセンフォード、
ウィンナーライダー、プリマドンナ、マリリンミナコーである。


## 自動発生の内部条件

月内の日付を抽選して発生予定を設定するイベントがある。
以下の値は画面のコイン数ではなく、[評価](22_evaluation.md) の内部値である。

| イベント         | 判定               | 条件                                                                                                                     |
| ---------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 消費者団体来訪   | 7 日ごとの来園判定 | 乱数値が 5 未満。発生は通算 10 回まで                                                                                    |
| 雑誌・テレビ紹介 | 7 日ごとの来園判定 | 知名度が 50 以上かつ、ヤングまたはカップルの評価が 200 超、4 区分の平均が 0 以上。知名度帯ごとに異なる乱数しきい値を使う |
| 人気タレント来訪 | 7 日ごとの来園判定 | 知名度が 100 超かつ、快適性とムードがともに 300 超。知名度帯ごとに異なる乱数しきい値を使う                               |
| 雑誌・テレビ紹介 | 月内日付の予定設定 | 知名度が 50 以上かつ、4 来園者区分の評価がすべて 501 以上。月内の発生数が 2 件未満                                       |
| 人気タレント来訪 | 月内日付の予定設定 | 知名度が 200 以上かつ、安全性、快適性、ムード、4 区分の平均の合計が 2,000 以上。発生予定がない                           |
| 映画撮影         | 月内日付の予定設定 | 知名度が 150 以上かつ、快適性とムードの合計が 700 以上。発生予定がない                                                   |

雑誌・テレビ紹介と人気タレント来訪には、7 日ごとの来園判定とは別に、
月内の日付を抽選して発生予定を設定する判定もある。


## 紹介の効果

雑誌で「とても楽しいパーク」として紹介されると、知名度が 10 上がり、
安全性、快適性、興奮性、ムードが各 100 上がる。

「つまらないパーク」として紹介されると、安全性、快適性、興奮性、ムードが各 100 下がる。

雑誌記者が来訪して満足した場合は知名度と客層別評価が上がり、
不満の場合は客層別評価が下がる。

テレビによる紹介は雑誌より効果が大きい。
