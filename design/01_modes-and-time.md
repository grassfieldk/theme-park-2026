# モードと時間

ゲーム開始時にスタンダードまたはシナリオを選ぶ。


## ゲームモード

| モード       | 内容                                                            |
| ------------ | --------------------------------------------------------------- |
| スタンダード | 国と難易度を選んで自由に経営する                                |
| シナリオ     | 国ごとに異なる初期状態と達成条件がある。10 か国を順にクリアする |

スタンダードでは、年度末決算で知名度、安全性、快適性、興奮性、ムードの
すべてが 13 枚以上になるとエンディングになる。エンディング後も経営を続けられる。
エンディング後に再び同条件を満たしてもエンディングは再生されない。

シナリオでは 10 か国すべてをクリアするとエンディングになる。
シナリオでは初級を選べない。


## 難易度

| 難易度 | 撤去費用 | 研究開発 | 商品仕入 | 株式売買 |
| ------ | -------- | -------- | -------- | -------- |
| 初級   | 不要     | 自動     | 自動     | 不可     |
| 中級   | 必要     | 手動     | 自動     | 不可     |
| 上級   | 必要     | 手動     | 手動     | 可能     |

初級では、研究開発と商品仕入に費用がかからない。
中級・上級では、研究開発への月ごとの投資額を設定する。

商品仕入が自動のとき、商品の販売益は売値から仕入値を引いた額である。
商品仕入が手動のとき、仕入時に仕入金を支払うため、販売益は売値そのものである。


## 開始時の資金

スタンダードの初期資金は国に寄らず一律 300,000 である。
シナリオの初期資金は国ごとに異なり、[シナリオ](02_scenarios.md) に記載する。


## 開始日と暦

| 項目     | 内容                     |
| -------- | ------------------------ |
| 開始日   | 2026 年 4 月 1 日        |
| 月の日数 | 通常のグレゴリオ暦と同じ |


## ゲーム速度

ゲーム速度は 3 段階 + 一時停止から選べる。ゲーム開始時は標準速度。
高速・標準・低速のゲーム内時間の進行比率は 4:2:1 である。

なお、メニューを開いている際は自動的に一時停止される。メニューを閉じると解除され元の速度に戻る。


## 日付に連動する処理

| 処理           | 内容                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| 7 日ごとの更新 | 施設・スタッフに関する順位情報などを更新、評価に使う値を更新する           |
| 年度末決算     | 3 月 31 日の後に決算とパーク評価を行う                                     |
| 労使交渉       | 4 月 10 日に行う                                                           |
| 仕入交渉       | 10 月 20 日に行う                                                          |
| 画面メッセージ | 日付により表示条件を判定する                                               |
| 資金不足       | 資金残高が負になると警告を表示し、資金残高が正に戻るまで警告状態を維持する |

年度末決算を経て、2 年連続で資金が赤字の場合はゲームオーバーになる。


## 定期交渉

4 月 10 日の労使交渉ではスタッフにかかる費用が、10 月 20 日の仕入交渉では商品の仕入価格が、それぞれ交渉結果に応じて変動する。

交渉画面では、パーク側の提示案件と相手側の要求案件を並べて表示する。
プレイヤーは提示案件を左右操作で増減できる。要求案件は交渉中に自動で変化する。
両案件の合計が成立条件に達すると交渉が成立する。制限時間内に成立しない場合は決裂する。

| 交渉     | 成立時の処理                                                              | 決裂時の処理                   |
| -------- | ------------------------------------------------------------------------- | ------------------------------ |
| 仕入交渉 | 22 種類の商品の仕入値を結果の増減率で変更する。同率なら仕入値は変わらない | 商品の仕入を停止する           |
| 労使交渉 | 6 職種のスタッフの賃金を結果の増減率で変更する。同率なら賃金は変わらない  | 組合との賃金協定を締結できない |

労使交渉が成立するとスタッフの能率が回復し、決裂すると能率が大幅に下がる。
再交渉では相手側の要求条件が厳しくなる。
相手側の要求条件は、前年度の交渉の成立状況によって変わる。
