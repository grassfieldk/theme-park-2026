# 施設の配置と撤去

施設を設置すると、パーク上のタイルを占有する。施設ごとに設置費があり、
資金不足の場合は設置できない。


## 配置処理

| 項目       | 内容                                 |
| ---------- | ------------------------------------ |
| 設置数上限 | 同時に設置できる施設は 64 件         |
| 資金       | 設置費を基に資金不足を確認する       |
| 占有領域   | 配置予定の全タイルを確認する         |
| 設置後     | 占有したタイルは施設に割り当てられる |


## 設置条件

| 対象           | 設置または変更の条件                               |
| -------------- | -------------------------------------------------- |
| 共通           | 人または施設がある場所には設置できない             |
| 一部の施設     | 高さが一定の平地にのみ設置できる                   |
| 歩道上の設備   | 歩道以外には設置できない                           |
| コース         | 安全のためコースに接する場所には施設を設置できない |
| コース         | 高さに上限がある                                   |
| コース         | 休止中だけ設置・変更できる                         |
| コース         | 撤去は端からのみ行える                             |
| コースの乗車口 | 一周していないコースには設置できない               |

設置対象ごとに、パーク内に 1 つだけ設置できるものがある。
コース型アトラクションは 1 種類につき 1 つまで設置できる。


## 撤去

施設を撤去すると、占有していたタイルが解放される。
アトラクションは運転中には撤去できない。
修理中のアトラクションも撤去できない。

コース型アトラクションを撤去すると、乗車口から切り離されたコースとオプションも
すべて撤去される。


## 設置による効果

設備を設置すると、そのときパーク全体の評価が加算され、周囲にいる来園者の機嫌も増減する。
機嫌が変わる範囲は設備の大きさに応じて広がる。トイレ、スーパートイレ、ゴミバコは
設置した瞬間だけ周囲の来園者の機嫌を下げるが、パーク評価は大きく上げる。

施設の設置時には、資金が 100,000 増える財宝発見がランダムに発生する。
