# ショップ

ショップの種類は飲み物、食べ物、お土産、ゲームの 4 つである。すべて 5 × 5 である。
接客数、初期仕入価格、開発費は [施設仕様](11_facility-specifications.md)、
設置費と維持費は [経済](12_economy.md) に記載する。


## 設定項目

| 対象           | 設定できる項目                                                               |
| -------------- | ---------------------------------------------------------------------------- |
| ショップ       | 販売価格、名称、性能                                                         |
| ゲームショップ | ゲーム料金、賞品価格、勝率                                                   |
| 飲食ショップ   | 甘さ、肉、麺、シーフード、塩、タバスコ、辛さ、カフェイン、氷、水分の量を設定 |


## 味付け

飲食ショップの味付けは 5 段階(段階 0 から段階 4)で設定する。
設置直後は段階 0 である。

味付けを濃くするほど在庫の消費量が増え、来園者の評価が上がる。
消費量の倍率は [経済](12_economy.md) に記載する。

段階 0 では「食べ物がまずい」「飲み物がまずい」の反応が発生し、
段階 4 では「この店には満足だ」の反応が発生する。

コーラとビールでは、氷と水分の量を増やすほど中身の量が減るため、方向が逆になる。

| 味付け               | 効果                                                             |
| -------------------- | ---------------------------------------------------------------- |
| 甘さ                 | 濃くするとキッズに人気が出る。来園者が空腹になりにくくなる       |
| シオ、タバスコ、辛さ | 濃くすると来園者がのどを渇かせ、周囲の飲み物ショップの売上が上がる。濃すぎるとキッズのショップ評価が下がる |
| カフェイン           | 来園者の疲労度を軽減する。濃すぎるとショップ評価が下がる         |
| ニク                 | 多くすると商品コストが増える                                     |
| 氷、水分             | 多くすると中身の量が減る                                         |


## ゲームショップ

ゲームショップは商品在庫を使わず、ゲーム料金、賞品価格、勝率を設定する。
来園者が勝つと賞品価格が支出になる。

賞品額と勝率、ハマリ度は [施設仕様](11_facility-specifications.md) に記載する。

賞品が高すぎると「ゲームの賞品が安い」ではなく満足の反応が出るが、支出が増える。
勝率が低すぎると「ゲームに勝てるとは思えない」の反応が発生する。


## 利用条件と挙動

来園者はパークに入場した直後にはショップを利用しない。
アトラクションを利用したあとにショップを利用する。

飲み物ショップと食べ物ショップを利用した来園者はゴミを出す。
近くにゴミバコがない場合は歩道に捨てる。

在庫がなくなると販売を停止する。

ビアホールはキッズが利用できない。
ファミリーがビアホールを利用した場合は 3 人分の売上になる。

同種の商品を扱うショップが近接していると、来園者が分散して双方の売上が下がる。

トイレ、スーパートイレ、ゴミバコは、近くの飲食ショップの集客率を下げる。
