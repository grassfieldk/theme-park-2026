# ショップ

ショップの種類は飲み物、食べ物、お土産、ゲームの 4 つである。すべて 5 × 5 である。
接客数、初期仕入価格、開発費は [施設仕様](11_facility-specifications.md)、
設置費と維持費は [経済](12_economy.md) に記載する。


## 設定項目

設置済みのショップにカーソルを合わせて決定すると、運営設定のメニューが開く。
操作は [設備の設定メニュー](10_facilities.md#設定メニューの操作) に記載する。

| 対象                     | 項目                         | 範囲                             |
| ------------------------ | ---------------------------- | -------------------------------- |
| お土産ショップ           | 販売価格 / 性能              | 0 〜 9,999 / Lv. 0 〜 9          |
| 飲食ショップ             | 販売価格 / 味付け / 性能     | 同上 / 段階 0 〜 4 / Lv. 0 〜 9  |
| ゲームショップ           | ゲーム料金 / 性能            | 同上 / Lv. 0 〜 9                |
| 賞品のあるゲームショップ | + 賞品価格 / 勝率            | 0 〜 9,999 / 0 〜 100 ％         |

味付けの項目名は店ごとに違う(下表)。性能は 10,000 払ってレベルを 1 上げると
接客数が増える。上限はバージョン 0 と 9 のときの接客数
([施設仕様](11_facility-specifications.md))の間を等間隔に割り振って求める。

メニューの反対側にはステータスの枠が出る。中身は
販売価格 / 仕入価格(ゲームはゲーム料金 / 賞品価格)、接客数、販売品目、経費、勝率、
ハマリ度、利用者数 先月 / 今月、味付けである。
在庫数／倉庫収容量と撤去費用は、その仕組みがまだないので出さない。

原作にある名前とミニゲームは本作では扱わない。
名前はかな入力が、ミニゲームは中身がそれぞれ未実装なため。


## 味付け

飲食ショップの味付けは 5 段階(段階 0 から段階 4)で設定する。
設置直後は段階 0 である。項目名は店ごとに決まっている。

| 項目名         | ショップ                               |
| -------------- | -------------------------------------- |
| 甘さの量       | ウォーリーアイス、クレクレクレープ     |
| ニクの量       | ビッグバーガー、ステーキハウス         |
| メンの量       | ちんらいけん、にほんてい               |
| グの量         | エブリーキッチン                       |
| シーフードの量 | シーフードレストラン                   |
| シオの量       | ポンポンコーン                         |
| タバスコの量   | ピザマルカジリータ                     |
| 辛さの量       | ヒリカラカレー                         |
| カフェインの量 | コーヒーショップ                       |
| 氷の量         | ドンキーコーラ                         |
| 水分の量       | ビアホール                             |

味付けを濃くするほど在庫の消費量が増え、来園者の評価が上がる。
消費量の倍率は [経済](12_economy.md) に記載する。

段階 0 では「食べ物がまずい」「飲み物がまずい」の反応が発生し、
段階 4 では「この店には満足だ」の反応が発生する。

コーラとビールでは、氷と水分の量を増やすほど中身の量が減るため、方向が逆になる。

| 味付け               | 効果                                                             |
| -------------------- | ---------------------------------------------------------------- |
| 甘さ                 | 濃くするとキッズに人気が出る。来園者が空腹になりにくくなる       |
| シオ、タバスコ、辛さ | 濃くすると来園者がのどを渇かせ、周囲の飲み物ショップの売上が上がる。濃すぎるとキッズのショップ評価が下がる |
| カフェイン           | 来園者の疲労度を軽減する。濃すぎるとショップ評価が下がる         |
| ニク                 | 多くすると商品コストが増える                                     |
| 氷、水分             | 多くすると中身の量が減る                                         |


### 味付けと欲求の変化

飲食ショップを利用すると、来園者の空腹値(食べ物を求める内部値)と
渇き値(飲み物を求める内部値)が商品と味付け段階に応じて変化する。
L は味付け段階 + 1(段階 0 〜 4 で 1 〜 5)である。値は 0 〜 255 の範囲に収められる。

| ショップ             | 空腹値の変化  | 渇き値の変化   |
| -------------------- | ------------- | -------------- |
| ウォーリーアイス     | -30 × L       | -              |
| ビッグバーガー       | -40 × L       | -              |
| ポンポンコーン       | -80           | +10 × L        |
| ステーキハウス       | -50 × L       | -              |
| ピザマルカジリータ   | -120          | +10 × L        |
| ドンキーコーラ       | -             | -120           |
| コーヒーショップ     | -             | -(6 - L) × 40  |
| ビアホール           | +(6 - L) × 10 | -60 × L        |
| シーフードレストラン | -60 × L       | -              |
| ちんらいけん         | -60 × L       | -              |
| クレクレクレープ     | -40 × L       | -              |
| ヒリカラカレー       | -120          | +10 × L        |
| にほんてい           | -60 × L       | -              |
| エブリーキッチン     | -40 × L       | -              |

設定には段階 0(L = 1)のときの値を持たせ、段階に比例するもの・薄いほど効くもの・
段階によらないものの 3 通りの決まりで、そこから段階ごとの値を求める。


### 店の評価

利用した来園者はそのつど店の点数を出す。点数は次の合計を -1,023 から 1,023 に
収めたものである。

| 項目   | 計算                                     |
| ------ | ---------------------------------------- |
| 値段   | (15 - 販売価格 × 10 ÷ 仕入価格) × 100    |
| 味付け | 系統ごとに下表                           |

| 系統                                   | 味付けの点数           | 不満が出る段階 |
| -------------------------------------- | ---------------------- | -------------- |
| 甘さ、ニク、メン、シーフード           | (段階 - 2) × 200       | 段階 0         |
| シオ、タバスコ、辛さ、カフェイン       | -\|段階 - 2\| × 100    | 段階 0 と 4    |
| 氷、水分                               | (2 - 段階) × 200       | 段階 4         |

不満が出ると「食べ物がまずい」「飲み物がまずい」の反応が発生し、
店の評価がさらに 100 下がる。仕入価格は [施設仕様](11_facility-specifications.md)、
点数と気分・店の評価への反映は [評価](22_evaluation.md) に記載する。

利用すると来園者の疲労が 100 回復する。

原作には、同じ種類の店の相場より販売価格が高いと店の評価が下がる処理もあるが、
相場の求め方が未確定のため本作では未実装である。


## ゲームショップ

ゲームショップは商品在庫を使わず、ゲーム料金、賞品価格、勝率を設定する。
利用のたびに人数ぶん勝率で判定し、勝った人数 × 賞品価格が支出になる。
賞品のないゲームセンターとうらないのやかたには、賞品価格と勝率の項目が出ない。

賞品額と勝率、ハマリ度は [施設仕様](11_facility-specifications.md) に記載する。

賞品が高すぎると「ゲームの賞品が安い」ではなく満足の反応が出るが、支出が増える。
勝率が低すぎると「ゲームに勝てるとは思えない」の反応が発生する。


## 利用条件と挙動

来園者はパークに入場した直後にはショップを利用しない。
アトラクションを利用したあとにショップを利用する。

来園者は空腹値・渇き値が 150 以上になると対応する飲食ショップへ向かう。
空腹と渇きの両方が 150 以上の場合は食べ物ショップを先に探す。
店に着いたとき対応する内部値が 50 未満なら利用しない。
接客時間は 1 人あたり 45 フレーム(標準速度で 0.3 日)である。

来園者は入口(店の前の道の 1 マス外)まで道路を歩き、そこから敷地の前端
(店の前の道のいちばん外側のマス)へ 1 マス入った位置で利用する。
設置時にこのマスに利用位置の目印が付き、隣まで来た来園者は店のほうを向いて
1 マスだけ敷地へ進んでから接客に入る。利用が終わると入口へ 1 マス出て徘徊に戻る。

利用中の来園者の表示はショップごとに 2 通りある。
屋台型は利用位置に立ち止まった姿を表示したまま利用し、
店舗型は店内へ入ったことを表す(利用中は表示されない)。

| 型     | ショップ                                                                                                                                                                     |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 屋台型 | ウォーリーアイス、ビッグバーガー、ポンポンコーン、ドンキーコーラ、コーヒーショップ、クレクレクレープ、エブリーキッチン                                                         |
| 店舗型 | ステーキハウス、ピザマルカジリータ、ビアホール、バラエティショップ、トイザマス、ラッキーショット、コングダンク、ゲームセンター、うらないのやかた、シーフードレストラン、ちんらいけん、ヒリカラカレー、にほんてい |

飲み物ショップと食べ物ショップを利用した来園者はゴミを出す。
近くにゴミバコがない場合は歩道に捨てる。

在庫がなくなると販売を停止する。

ビアホールはキッズが利用できない。
ファミリーがビアホールを利用した場合は 3 人分の売上になる。

同種の商品を扱うショップが近接していると、来園者が分散して双方の売上が下がる。

トイレ、スーパートイレ、ゴミバコは、近くの飲食ショップの集客率を下げる。
