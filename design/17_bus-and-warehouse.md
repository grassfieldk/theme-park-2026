# バスと倉庫

バスは来園者と帰宅する来園者を運ぶ。倉庫は上級で仕入れた商品を保管する。


## バス

来園時は、バスの定員を超える来園希望者は入園できない。
帰宅時もバスを使うが、帰宅者を乗せられる人数は定員ではなく、停車時間に依存する。
バスの停車時間はゲーム速度の影響を受けない。
バスは 7 日ごとに来る。前のバスがまだ走っている場合、その週は見送られる。

| バージョン |  開発費 | 定員 |
| ---------- | ------: | ---: |
| 1          |       - |   15 |
| 2          |  10,000 |   20 |
| 3          |  20,000 |   30 |
| 4          |  30,000 |   40 |
| 5          |  40,000 |   50 |
| 6          |  50,000 |   60 |
| 7          | 100,000 |   70 |
| 8          | 150,000 |   80 |
| 9          | 200,000 |   90 |
| 10         | 200,000 |  100 |

バスの定員が不足していると、定員を上げるアドバイスが表示される。

バスの車体は先頭・中間・後尾の 3 部品の連結で、中間はバージョンの数だけ 16px 間隔で
増える(バージョンが上がるほど車体が長くなる)。バージョン 1〜5 と 6〜10 で車体の
デザインが変わる。バスは画面右端からゲート下の道路を左へ走り、ゲート近くの停車位置で
停まって乗降し、終わるとさらに左へ走り抜けて画面外へ出る。


## 倉庫

上級では、飲食ショップで販売する商品を仕入れて倉庫に保管する。
倉庫の収容量を超えて仕入れることはできない。

| バージョン |  開発費 | 収容量 |
| ---------- | ------: | -----: |
| 1          |       - |  1,000 |
| 2          |  50,000 |  2,000 |
| 3          |  50,000 |  3,000 |
| 4          | 100,000 |  4,000 |
| 5          | 100,000 |  5,000 |
| 6          | 100,000 |  6,000 |
| 7          | 150,000 |  7,000 |
| 8          | 150,000 |  8,000 |
| 9          | 150,000 |  9,000 |

上級では発注から 7 日後に在庫へ加算される。
