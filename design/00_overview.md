# ゲーム概要

本作はテーマパークを運営するゲームである。国は日本、アメリカ、ブラジル、イギリス、
フランス、エジプト、ロシア、インド、中国、オーストラリアの 10 種類である。


## 画面表現

パークの地形と施設は、2D の画像で高低差を表現する。来園者は方向別の 2D 画像で表現される。


## ゲームの流れ

プレイヤーは国とモードを選び、初期化されたパークを経営する。
パーク内に道路と施設を設置し、スタッフ、価格、研究開発、広告などを管理する。

来園者は道路を移動して施設を利用し、価格や施設、パーク環境に反応する。
時間の進行に合わせて収支と評価が更新され、イベントやモード固有の処理が行われる。


## メニューカテゴリ

| カテゴリ | 操作                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 建設     | 道路・モノレール、アトラクション、ショップ、設備の設置                                              |
| 人員     | スタッフの雇用と管理                                                                                |
| 経営     | 資金、価格、仕入れ、研究開発、イベント、広告                                                        |
| 情報     | パーク状況、アトラクション、ショップ、スタッフ、マーカーの表示                                      |
| システム | セーブ、ロード、アドバイス、ゲーム速度、BGM、全体マップ、視点変更、視点モード、パークへ出かける操作 |

ヘルプモードでは、施設の設置と撤去、経営、システムの説明を参照できる。
ゲームの進行を一時停止できる。

本作では原作にない項目として、システムに「操作設定」を置いている。
画面に出す操作ボタンの絵柄(PlayStation / Xbox)と、決定と取り消しの入れ替えを選べる。
設定はセーブデータとは別に、ブラウザに残る。


## セーブ

セーブデータはアトラクションや道路のゴミなどのマップの状態、現在の日付、資金などの経営データを原則すべて保存する。
ただし来園客の位置は保持しない。つまり、ロードした際は来園者がすべてクリアされることになる。


## 情報表示

パーク状況では、資金残高、収入、支出、来園者数、入場料収入、乗車額収入、
ショップ収入、人件費、総合評価のグラフ表示を切り替えられる。表示する年数も変更できる。

アトラクション情報には、運転状態、乗車額、定員数、耐久度、興奮度、
経費、速度、利用者数、運転時間、撤去費用が表示される。

ショップ情報には、販売価格、仕入価格、接客数、販売品目、在庫数、倉庫収容量が表示される。

スタッフ情報には、月給、雇用年数、能率、職種、ウケた数が表示される。

来園者情報には、所持金、乗車数、おみやげの数、気分、滞在時間、気持ちが表示される。
