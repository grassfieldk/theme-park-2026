# シナリオ

シナリオでは国ごとに開始資金、借入限度額、経済状態、土地の規模、期限、達成条件が異なる。
達成条件はゲーム進行中に継続して判定され、満たした時点で成功となる。
期限を過ぎても未達の場合は失敗となる。

## 経済状態

経済状態は来園者の所持金と、価格設定に対する反応に関係する。

| 経済状態 | 国                                 |
| -------- | ---------------------------------- |
| 超リッチ | フランス、日本、イギリス、アメリカ |
| ふつう   | エジプト、中国、オーストラリア     |
| ビンボー | インド、ブラジル、ロシア           |
